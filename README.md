# Unmatched Browser

Приложение Unmatched Browser позволяет просматривать информацию о наборах, героях и картах из настольной игры Unmatched<sup>TM</sup>. 

## Функционал приложения
1. Просмотр информации о наборе: списках героев и полей битв, входящих в набор.
2. Просмотр информации о герое: характеристиках, способности и колоде карт.
3. Просмотр информации о полях битв.
4. Просмотр информации о картах.

## Реализация
Приложение разработано на языке Python 3 с использованием библиотек PyQt6 и SQLite3.

Настольная игра Unmatched<sup>TM</sup> является собственностью компании Restoration Games, LLC.  
Все изображения, используемые в приложении, взяты с сайта [the-unmatched.club](https://www.the-unmatched.club/).
